# ⭐ Projeto em destaque

## 🧑‍💻 CIESA-CodeLab

O **CIESA-CodeLab** é uma plataforma web voltada para o **ensino e prática de programação**, desenvolvida com o objetivo de proporcionar aos estudantes um ambiente onde possam resolver exercícios, enviar códigos e receber resultados de execução e correção.

O projeto é inspirado em plataformas de ensino e correção automática de programação, buscando aproximar o ambiente acadêmico de uma experiência prática de desenvolvimento.

### 🏗️ Tecnologias utilizadas

`React` · `TypeScript` · `Node.js` · `Express` · `PostgreSQL` · `Prisma` · `Redis` · `Docker`

### 🔧 Principais funcionalidades e conceitos

* 👤 Gerenciamento de usuários
* 🔐 Autenticação e controle de permissões
* 👨‍🏫 Professores e estudantes
* 📚 Cursos, disciplinas e turmas
* 📝 Criação e gerenciamento de exercícios
* 💻 Editor de código
* ▶️ Execução de códigos
* 🧪 Correção automática
* 🔄 Processamento de execuções através de filas
* ⚡ Redis para processamento de jobs
* 🐳 Ambientes isolados para execução de código
* ☕ Execução de Java
* 🐍 Execução de Python
* 📊 Registro de tentativas e resultados
* 🗄️ Persistência de dados com PostgreSQL
* 🔌 APIs para comunicação entre frontend e backend
